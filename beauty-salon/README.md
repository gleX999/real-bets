# Queen Studio: лендинг салона красоты (черновик)

Одностраничный сайт салона Queen Studio (Husova 557, 274 01 Slaný) в стиле логотипа: чёрный и золото. Чистые HTML, CSS и JS, без сборки и зависимостей.

## Файлы

- `index.html` — разметка. Тексты по умолчанию на чешском, для поисковиков.
- `js/i18n.js` — все тексты на трёх языках: чешском, английском и украинском. Ключи совпадают с атрибутами `data-i18n` в разметке.
- `js/main.js` — скрипты. Настройки записи и карты лежат в объекте `SALON` в начале файла.
- `css/style.css` — стили. Цвета, шрифты и отступы собраны в `:root`.
- `favicon.svg` — иконка вкладки: корона в кольце.

Посмотреть локально: `python3 -m http.server` в этой папке, затем открыть http://localhost:8000. Заставку можно показать повторно через адрес с `#intro`.

## Что уже работает

- **Заставка с логотипом** при первом заходе, один раз за визит, около трёх секунд. Её можно пропустить кликом, клавишей или прокруткой. При системной настройке «уменьшить движение» заставка не показывается.
- **Логотип перерисован в векторе.** Надпись набрана шрифтом Libre Baskerville, «beauty salon» шрифтом Great Vibes. Кольцо собрано из двух окружностей, поэтому оно толще справа внизу, как в оригинале.
- **Языки CZ / EN / UA с флагами.** Язык определяется по браузеру: cs и sk открывают чешский, uk и ru украинский, остальные английский. Выбор посетителя запоминается.
- **Цены в кронах** с форматом под язык: «1 200 Kč» или «CZK 1,200».
- **Оплата:** Visa, Mastercard, Apple Pay, Google Pay, наличные. Знаки взяты из Simple Icons (лицензия CC0).
- **Карта Google** на настоящем сайте загружается только по кнопке, чтобы не ставить cookies без согласия (GDPR).

## Что заменить перед запуском

- [ ] Видео для первого экрана: девушка со спины или вполоборота поправляет волосы. Файл `media/hero.mp4` (до 5 МБ, 1080p) и постер `media/hero.jpg`. Тег `<video class="hero__video" autoplay muted loop playsinline>` вставить в `.hero__media`. Кнопка паузы в круглом значке появится сама.
- [ ] Видео для перехода к маникюру: рука разжимается и показывает маникюр. Вставить `<video data-scrub muted playsinline preload="auto">` в `.mani__media`. Тогда кадр будет раскрываться вместе с прокруткой. Для плавной прокрутки видео нужно перекодировать с ключевым кадром на каждом кадре.
- [ ] Фото интерьера (`.about__media`), услуг (`.svc-card__img`), мастеров (`.master__portrait`) и работ (`.tile`).
- [ ] Телефон, часы работы, IČO, ссылки на Instagram, Facebook, WhatsApp и Telegram.
- [ ] Цены, мастера и стаж: сейчас примерные.
- [ ] Отзывы: только настоящие, из Google. Примеры отмечены плашкой «Ukázková recenze».
- [ ] Онлайн-запись: вписать ссылку в `SALON.booking.url`. Рекомендую Reservio. Пока ссылки нет, кнопки открывают окно с телефоном.
- [ ] Страница «Ochrana osobních údajů» (политика GDPR).
- [ ] Удалить плашку черновика (`#draft-bar`) и все пометки `.todo-note`.
