# AURUM: лендинг салона красоты (черновик)

Одностраничный сайт в стиле «тёмный люкс»: первый экран с анимированным фоном, преимущества, услуги, прайс, мастера, работы, отзывы, контакты с картой. Чистые HTML, CSS и JS, без сборки и зависимостей.

## Файлы

- `index.html` — разметка и тексты.
- `css/style.css` — стили. Цвета, шрифты и отступы собраны в `:root` в начале файла.
- `js/main.js` — скрипты. Настройки интеграций лежат в объекте `SALON` в начале файла.
- `favicon.svg` — иконка вкладки (арка, как в логотипе).

Посмотреть локально: `python3 -m http.server` в этой папке, затем открыть http://localhost:8000.

## Что заменить перед запуском

- [ ] Название AURUM — рабочее, заменить на настоящее (логотип, `<title>`, подвал).
- [ ] Адрес, телефон, часы работы: поиск по `Примерная` и `000-00-00` в `index.html`, плюс блок JSON-LD в `<head>`.
- [ ] Логотип: сейчас текстовый со знаком-аркой.
- [ ] YCLIENTS: вписать в `SALON.yclients.widgetSrc` адрес скрипта из кода виджета (вида `https://w123456.yclients.com/widgetJS`). После этого все кнопки «Записаться» открывают виджет. Пока поле пустое, показывается запасное окно с телефоном.
- [ ] Карта: вписать координаты салона в `SALON.map`. Тогда вместо схемы-заглушки загрузится Яндекс Карта.
- [ ] Прайс, мастера, стаж: сейчас примерные.
- [ ] Фото мастеров и работ: заменить плитки-заглушки на снимки.
- [ ] Отзывы: только настоящие (перенести с Яндекс Карт или встроить их виджет). Примеры отмечены плашкой «Пример отзыва».
- [ ] Ссылки на WhatsApp, Telegram, ВКонтакте, маршруты в Яндекс Картах и 2ГИС.
- [ ] Реквизиты ИП или ООО и страница политики конфиденциальности.
- [ ] Удалить плашку черновика (`#draft-bar`) и все пометки `.todo-note`.

## Анимация первого экрана

Функция `initSilk` в `js/main.js` рисует на canvas две ленты из тонких золотых прядей. Они колышутся и закручиваются, по ним пробегает блик, как блеск ухоженных волос. Поверх медленно поднимается золотая пыль, курсор даёт лёгкий параллакс, за прядями стоит арка-зеркало.

- Анимация ставится на паузу, когда первый экран не виден или вкладка неактивна.
- При системной настройке «уменьшить движение» рисуется один статичный кадр.
- На телефонах прядей меньше, чтобы не нагружать устройство.

Количество, яркость и форму лент можно менять в `configs` внутри `layout()`.
